# Mariya Beauty Bot — Telegram-бот для студии Марии Федосеевой

Бот @MariyaFedoseevaHelp_bot — автоматизация для студии красоты в Сызрани.

## Что умеет

| Команда | Что делает |
|---|---|
| `/start` | Приветствие + главное меню |
| `Записаться` | Пошаговая запись на услугу с записью в Google Sheets |
| `Услуги и цены` | Полный прайс с кнопками записи |
| `Обучение` | Описание курсов + онлайн-уроки |
| `Контакты` | Телефон, Telegram, адрес студии |
| `Адрес` | Адрес + ссылка на Яндекс Карты |
| `Отзыв` | Сбор отзыва (1-5 + текст) |
| `Бонусы UDS` | Запрос баллов по номеру телефона |
| `/cancel` | Отмена любого действия |

## Структура диалогов

### Сценарий записи
```
Пользователь → "Записаться"
Бот → "Выбери тип услуги" (кнопки: Макияж / Укладка / Брови / Обучение / Другое)
Пользователь → "Макияж"
Бот → "Какой именно?" (кнопки: Дневной / Вечерний / Свадебный / Графичный)
Пользователь → "Свадебный"
Бот → "Когда удобно?" (кнопки: Сегодня / Завтра / На этой неделе / Выбрать дату)
Пользователь → "Завтра"
Бот → "Доступные слоты" (кнопки: 10:00, 12:00, 14:00, 16:00, 18:00)
Пользователь → "14:00"
Бот → "Подтверди запись" (кнопки: ✅ Всё верно / ❌ Отмена)
Пользователь → "✅ Всё верно"
Бот → "Записал тебя на Завтра 14:00, Свадебный макияж. Мария свяжется для подтверждения. 💛"
        + Уведомление Маше в её личку с полными данными
        + Запись строки в Google Sheets (лист "Записи_бот")
```

## Технологии

- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **gspread** — интеграция с Google Sheets
- **Webhook** через aiohttp (для деплоя на Render.com)

## Как задеплоить

### 1. Получи токен бота
1. Открой @BotFather в Telegram
2. `/mybots` → выбери `MariyaFedoseevaHelp_bot`
3. Скопируй токен (формат: `7000000000:AAxxxxx...`)

### 2. Узнай свой Telegram ID
1. Открой @userinfobot
2. Напиши ему `/start`
3. Он пришлёт твой ID (число, например `123456789`)

### 3. Задеплой на Render.com

**Способ 1: через GitHub**
1. Создай приватный репозиторий на GitHub
2. Залей файлы `bot.py`, `requirements.txt`, `render.yaml`
3. Зайди на https://render.com (через Google)
4. New → Blueprint → подключи репо
5. В Environment Variables добавь:
   - `BOT_TOKEN` = твой токен
   - `ADMIN_CHAT_ID` = твой Telegram ID
6. Deploy

**Способ 2: напрямую через Render CLI**
1. Установи Render CLI: `curl -sL https://render.com/download-cli/install.sh | bash`
2. В папке с проектом: `render blueprint launch`
3. Следуй инструкциям

### 4. После деплоя

Бот начнёт работать автоматически. Подожди 1-2 минуты. Проверь:
1. Открой @MariyaFedoseevaHelp_bot
2. Нажми `/start`
3. Должно появиться приветствие с меню

## Что внутри кода

### handlers/
- `start.py` — приветствие, главное меню
- `services.py` — прайс услуг
- `booking.py` — пошаговая запись
- `education.py` — обучение и онлайн-уроки
- `contacts.py` — контакты и адрес
- `reviews.py` — сбор отзывов
- `bonuses.py` — проверка баллов UDS
- `admin.py` — админ-команды (для Маши)

### config.py
- Услуги и цены
- Тексты приветствий
- Ссылки (Telegram, VK, Instagram, UDS)
- Адрес студии
- Слоты времени (временные интервалы)

### storage/google_sheets.py
- Принимает данные записи
- Добавляет строку в лист "Записи_бот"

### keyboards.py
- Все инлайн-кнопки (для каждого шага)

### states.py
- FSM-состояния (RecordingServiceType, RecordingSpecific, RecordingDate и т.д.)

## Что нужно изменить под себя

В `config.py`:
- `SERVICES` — список услуг и цен
- `WELCOME_TEXT` — приветственное сообщение
- `EDUCATION_COURSES` — список курсов
- `STUDIO_INFO` — контакты студии
- `TIME_SLOTS` — доступные слоты
- `ADDRESS` — адрес студии

## Проверка работы локально

Бот не сможет отвечать в Telegram без публичного URL. Но можно:
1. Запустить `python bot.py` локально
2. Если стоит `debug_polling = True` — бот поллит обновления
3. Открыть бота в Telegram → проверить

Для теста без деплоя поставь `DEBUG_POLLING=True` в `bot.py`.
